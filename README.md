# 數藥小幫手（Pill Counter PWA）

用 iPhone 相機數藥錠數量、核對處方數量，避免發藥時數錯。個人非營利工具，所有影像都在手機內運算，不上傳任何資料。

## 在 iPhone 上安裝（當成 app 用）

1. 用 Safari 打開部署網址（見下方「部署」）。
2. 點下方「分享」鈕 → 「加入主畫面」→ 「新增」。
3. 之後從主畫面的「數藥」圖示開啟，就是全螢幕、可離線使用（第一次開啟需要連網載入）。
4. 第一次按「拍照計數」時，Safari 會問是否允許使用相機，選「允許」。

## 怎麼用

1. 輸入「預定數量」（可點 28、30、56 等快速鍵）。
2. 把藥平鋪在**深色托盤或深色紙**上，盡量不重疊、彼此留一點空隙，從正上方拍。
3. 按「拍照計數」。畫面上每顆藥都會畫圈並編號，左上角顯示總數與「與預定相符／多幾顆／少幾顆」。
4. 綠圈＝正常；**橘圈＝程式沒把握（相連、形狀怪、靠邊）**，請目視確認；藍圈＝你手動補的。
5. 漏抓的藥：點一下該位置補標記；誤抓的：點一下標記移除。數量會即時更新。
6. 「存紀錄」會把藥名、預定數、數到的數存在手機裡（只在這支手機）。
7. 「即時計數」開啟後，不用按拍照，鏡頭對著藥就會持續顯示數量（較耗電、較粗略；正式核對請用拍照）。

### 拍不好時

| 現象 | 調整 |
|---|---|
| 陰影、反光、托盤刮痕被當成藥 | 設定 → 靈敏度往右（正值）；或開「顯示辨識範圍」看哪裡被塗到 |
| 顏色淺的藥抓不到 | 靈敏度往左（負值）；換深色托盤 |
| 白藥放白紙上 | 幾乎抓不到，請換深色底；深色藥則用白紙 |
| 黏在一起的藥算成一顆 | 把藥撥開一點再拍；確認「自動拆分相連藥錠」有開 |
| 有刻痕的錠被算成兩顆 | 程式會自動合併兩個半圓；若仍錯，點掉多的標記 |
| 藥很小、很多 | 設定 → 解析度 1400；鏡頭靠近一點 |

**辨識結果只是輔助，發藥前仍以目視複核為準。**

## 運作原理（counter.js）

純 JavaScript、不需伺服器，瀏覽器與 Node 共用同一支程式：

1. **背景估計**：取影像外框帶狀區域的眾數色當托盤色，再把影像切成格子，每格各自估一次（修正光線漸層），缺格由鄰格補、再平滑。
2. **特徵圖**：每個像素與局部背景的顏色距離（0–255）。因此白藥配深托盤、深色藥配白紙都能用，不限顏色。
3. **門檻**：先從直方圖的背景峰估出雜訊水準，再在雜訊水準以上做 Otsu 自動門檻（避免藥很少時 Otsu 被托盤自己的明暗差騙走）。
4. **形態學**：閉運算補刻痕、開運算去雜點，半徑依估計出的藥錠內切圓半徑 R 自動調整。
5. **距離轉換（EDT）**：Felzenszwalb 精確歐氏距離轉換。做兩份：未填洞版找波峰（保留三、四顆互靠時中間的小空隙），填洞版做頸部測試與面積。
6. **拆分相連藥錠**：每個連通元件取 EDT 局部極大值 → 非極大抑制 → **頸部測試**（兩波峰連線上的最小 EDT 若明顯小於波峰，中間有「脖子」才算兩顆；長錠、膠囊、有壓印的錠不會被誤拆）→ 面積上限。
7. **後處理**：相鄰兩個半圓合起來很圓就合併成一顆；面積小於單顆中位數 30% 的視為雜點；數量與面積不一致或靠邊的標為不確定（橘色）。

## 測試

```bash
node test/run.mjs 400 2          # 400 張合成托盤影像（不同托盤色、藥形、相連率、陰影、漸層、雜點）
PC_OPTS='{"threshold":"pct"}' node test/run.mjs 400 2   # 覆寫參數做 A/B
```

失敗案例會輸出到 `test/out/`（畫好標記的 PNG）。目前合成測試完全正確率約 97–98%，誤差多為 ±1 且會被標成橘色。真實照片請自行用手機實測並回饋調整。

```bash
node tools/make_samples.mjs      # 重新產生 samples/ 範例圖
node tools/make_icons.mjs        # 重新產生 icons/
```

## 本機預覽

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

打開 `http://127.0.0.1:8765/?img=samples/sample1.png` 可不經相機直接測試一張圖。

## 部署

純靜態檔案，任何靜態主機都能放（Vercel、GitHub Pages、Cloudflare Pages）。相機與離線快取需要 HTTPS。`vercel.json` 只設定了 `sw.js` 不快取，讓更新能即時生效。

## 關於 PillEye 等商業 app

PillEye（韓國 Medility）、Pill Counting 等商業 app 以相機即時或拍照計數，宣稱準確率 99.99%（廠商數字，無獨立驗證），採月費制，演算法未公開（官方訪談只提到以大量藥錠照片訓練多個模型）。本專案**沒有**反編譯或取用任何商業 app 的程式與模型，而是用公開文獻中成熟的古典影像處理方法（距離轉換＋分水嶺／波峰拆分）從頭實作，並針對藥局情境（托盤、刻痕錠、膠囊、相連）加上自己的規則。要再提升對奇形藥品與重疊的辨識，下一步是用自己拍的照片訓練小型物件偵測模型（例如 YOLO 系列匯出成 ONNX，在瀏覽器用 onnxruntime-web 跑），同樣可以完全離線。
